# hack

`wraith/` — a Fabric 1.21.x Minecraft client framework: module + setting registry,
event bus, JSON config profiles, keybinds, an animated click GUI and a HUD editor.

- Start at [wraith/README.md](wraith/README.md) for layout and build steps.
- [wraith/SCOPE.md](wraith/SCOPE.md) states what this project covers and what it will not grow into.
- [wraith/docs/BUILDING.md](wraith/docs/BUILDING.md) covers the version-specific API spots and the no-compiler checks used here.

`workspace-*/` is an earlier, unrelated snapshot of a `wraith` build (compiled jars and a
Gradle/Mojang download toolchain). It is kept as history; `wraith/` is the real source tree.
